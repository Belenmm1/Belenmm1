##  Main Project — MediGest Management 

**Live Demo:** https://medigest-managment-system-production.up.railway.app

Independent full-stack healthcare management platform built with secure backend architecture and real-world workflows.

**Backend** · [`medigest-backend`](https://github.com/Belenmm1/medigest-backend)

```txt
Node.js + Express   → REST API with JWT + Refresh Tokens
PostgreSQL          → Relational database + migrations + seeds
Redis               → Token blacklist, cache, and rate limiting
WebSockets          → Real-time updates and alerts
Security            → Helmet, CORS, bcrypt, audit logs
```

**Frontend** · [`medigest-MANAGMENT-SYSTEM`](https://github.com/Belenmm1/medigest-MANAGMENT-SYSTEM)

```txt
Vanilla JS ES6+     → Modular SPA architecture
HTML5 / CSS3        → Bilingual UI and role systems
Accessibility       → ARIA, keyboard shortcuts, high contrast
```

**Modules:**  
Patients · Appointments · Clinical History · Beds · Pharmacology · Audit · Auth & Roles · WebSockets
