🎀 VECTOR Centro de Datos
Operational data integration and traceability platform

Designed and developed independently after a requirements survey at TDS Misiones. The platform brings information from three business systems into a centralized PostgreSQL environment.
Source	Information integrated
Naaloo	HR information and geolocated clock-in / clock-out records
Geest	Work orders, quotes, service scheduling, payroll, expenses and income
Obersat	Satellite vehicle tracking


Geest does not expose a conventional database or API, so its information is extracted and normalized through n8n workflows. The platform is designed to maintain historical records, audit trails and traceability across sources.

The frontend uses React 19, TypeScript, Vite and Tailwind. The backend includes protected serverless API routes, session authentication, role-based permissions, user management, exports and audit events.

Modules: Control Center · Traceability · Expenses · Team · Calendar · Audit · Analytics
Stack: React · TypeScript · Vite · Tailwind · PostgreSQL · n8n

Repository available upon request.
🌸 PRISMA
Vertical SaaS for beauty and aesthetics businesses

PRISMA is a product within the VECTOR ecosystem, designed for beauty salons, aesthetics centers and independent professionals. It brings everyday operations that are often spread across WhatsApp, notebooks and spreadsheets into one place.

Main modules:

☁️ DocuFlow
Intelligent document processing SaaS

A multi-service application for asynchronous analysis of PDF, Word and spreadsheet files. It includes document classification, RAG-based document chat, semantic search with FAISS, OCR fallback and AI-assisted comparison.

The architecture includes an API, worker and Next.js frontend, with JWT authentication, Stripe payments, plan-based limits, Spanish / English localization and CI/CD on Railway.
