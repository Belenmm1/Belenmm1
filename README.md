## Proyecto Principal — MediGest Pro
**SISTEMA COMPLETO EN RAILWAY** : (https://medigest-managment-system-production.up.railway.app)

Sistema de gestión hospitalaria desarrollado de forma independiente, con arquitectura full-stack completa.

**Backend** · [`medigest-backend`](https://github.com/Belenmm1/medigest-backend)

```
Node.js + Express   →   API REST con autenticación JWT + Refresh Tokens
PostgreSQL          →   Base de datos relacional con migraciones y seeds
Redis               →   Blacklist de tokens, rate limiting y caché
WebSockets          →   Actualizaciones en tiempo real (camas, alertas)
Seguridad           →   Helmet, CORS, XSS sanitization, bcrypt, auditoría
```

**Frontend** · [`medigest-MANAGMENT-SYSTEM`](https://github.com/Belenmm1/medigest-MANAGMENT-SYSTEM)

```
Vanilla JS ES6+     →   SPA sin frameworks, modular y escalable
HTML5 / CSS3        →   UI bilingüe con sistema de roles y permisos
Accesibilidad       →   Alto contraste, atajos de teclado, ARIA
```

**Módulos:** Pacientes · Turnos · Historia Clínica · Camas · Farmacología · Auditoría · Auth & Roles · WebSocket
