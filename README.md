## MediGest — Hospital Information System

> A complete HIS built solo. Bilingual, secure, production-ready.

**[→ Live Demo](https://medigest-managment-system-production.up.railway.app)**

**Backend** · [`medigest-backend`](https://github.com/Belenmm1/medigest-backend)
```
Node.js + Express   → REST API with JWT + Refresh Tokens
PostgreSQL          → Relational schema + migrations + seeds
Redis               → Session cache, token blacklist, rate limiting
WebSockets          → Real-time alerts and updates
Security            → Helmet, CORS, bcrypt, immutable audit logs
```

**Frontend** · [`medigest-MANAGMENT-SYSTEM`](https://github.com/Belenmm1/medigest-MANAGMENT-SYSTEM)
```
Vanilla JS ES6+     → Modular SPA — zero UI frameworks
HTML5 / CSS3        → Bilingual UI, role-based views
Accessibility       → ARIA, keyboard shortcuts, high contrast mode
```

**Modules:** Patients · Appointments · Clinical History · Beds · Pharmacology · Audit · Auth & Roles · Real-time Comms
