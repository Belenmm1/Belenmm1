Cada tecnología tiene una razón. No hay stack por default acá. Every technology has a reason. No default stack here.

PostgreSQL
MongoDB — datos hospitalarios son relacionales por naturaleza. Paciente → turno → médico → historial. Un esquema flexible era una trampa. MongoDB — hospital data is relational by nature. Patient → appointment → doctor → history. A flexible schema was a trap.
Redis
Memcached — Redis ganó por estructuras de datos complejas y persistencia opcional. Con usuarios concurrentes, la diferencia importa. Memcached — Redis won for complex data structures and optional persistence. With concurrent users, the difference matters.
WebSockets
Polling cada N segundos — inaceptable en entorno hospitalario. Una alerta tiene que llegar al instante. Polling every N seconds — unacceptable in a hospital environment. An alert has to arrive instantly.
Vanilla JS + CSS modular
React / Vue — overhead innecesario. Resultado: 87% HTML, 13% JS, carga instantánea, cero deuda de dependencias. React / Vue — unnecessary overhead. Result: 87% HTML, 13% JS, instant load, zero dependency debt.
JWT + refresh tokens
Sessions en servidor — escala mal. JWT stateless funciona en arquitectura distribuida desde el primer deploy. Server sessions — scales poorly. Stateless JWT works in distributed architecture from the first deploy.

05 / 05 Aprendizajes Learnings

Lo más valioso no siempre está en el código. The most valuable lessons aren't always in the code.

01

La conexión con la base de datos me tuvo días trabada. El problema tenía una solución que en retrospectiva era obvia. Aprendí que los bugs más frustrantes casi nunca son los más complejos — y que quedarse estancada es parte del proceso, no una señal de que algo está mal. The database connection had me stuck for days. The problem had a solution that was obvious in retrospect. I learned that the most frustrating bugs are almost never the most complex — and that getting stuck is part of the process, not a sign that something is wrong.

02

Diseñar el esquema primero. Antes de escribir una sola ruta de API. Los datos hospitalarios son profundamente relacionales — empezar por ahí evitó semanas de refactoring. Design the schema first. Before writing a single API route. Hospital data is deeply relational — starting there avoided weeks of refactoring.

03

La seguridad no se agrega al final. Helmet, rate limiting y logs de auditoría estuvieron en el primer PR. Retrofitear seguridad en un sistema vivo es costoso y frágil. Security isn't added at the end. Helmet, rate limiting and audit logs were in the first PR. Retrofitting security into a live system is costly and fragile.

04

Bilingüe como decisión de arquitectura. No es traducción — son claves de contenido, no strings hardcodeados. Cambié el enfoque en la semana dos y valió cada hora. Bilingual as an architecture decision. It's not translation — it's content keys, not hardcoded strings. I changed the approach in week two and it was worth every hour.
